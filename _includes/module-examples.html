{%- comment -%} Lists every real-world example page in a module's examples folder, grouped by chapter - nothing to maintain by hand: add a page to the folder and it appears here. Usage (on the Examples and case studies page): {% include module-examples.html sidebar="module-data-management" folder="pages/modules/02-data-management/examples/" %} Within each chapter (chapters come from the sidebar, in order): - Node examples: pages in the folder whose `back_to` is the chapter, except those the chapter lists itself in related_pages. The chapter's optional `examples_intro` (Markdown in its front matter, e.g. a key to the Topics labels) is shown above them. - Case studies: the pages in the folder that the chapter lists in its related_pages (Real_world_example), so a case study used by several chapters appears under each. Pages that fit nowhere (no back_to, not related) are listed at the end, so none is missed. Each group is a grid of example cards (example-card.html), sorted by title - the same cards as "See it in practice". {%- endcomment -%} {%- assign mx_nav = site.data.sidebars[include.sidebar] -%} {%- assign mx_all = site.pages | where_exp: "p", "p.path contains include.folder" | sort: "title" -%} {%- assign mx_digits = "0123456789" | split: "" -%} {%- assign mx_placed = "" -%} {%- for item in mx_nav.subitems -%} {%- assign mx_c1 = item.title | slice: 0 -%}{%- assign mx_c2 = item.title | slice: 1 -%} {%- unless mx_digits contains mx_c1 and mx_digits contains mx_c2 -%}{%- continue -%}{%- endunless -%} {%- assign mx_url = item.url | remove_first: "/" -%} {%- assign mx_ch = site.pages | where_exp: "p", "p.url == item.url or p.url == mx_url" | first -%} {%- assign mx_related = mx_ch.related_pages.Real_world_example | default: "" -%} {%- assign mx_examples = "" | split: "" -%} {%- assign mx_cases = "" | split: "" -%} {%- for ex in mx_all -%} {%- if mx_related contains ex.page_id -%} {%- assign mx_cases = mx_cases | push: ex -%}{%- assign mx_placed = mx_placed | append: "|" | append: ex.page_id -%} {%- elsif ex.back_to == mx_ch.page_id -%} {%- assign mx_examples = mx_examples | push: ex -%}{%- assign mx_placed = mx_placed | append: "|" | append: ex.page_id -%} {%- endif -%} {%- endfor -%} {%- if mx_examples.size > 0 or mx_cases.size > 0 %}
